If you've ever prepared a presentation at Utrecht University, you'll know the struggle: PowerPoint templates [exist](https://www.uu.nl/en/organisation/corporate-identity/powerpoint-keynote) and get the job done, but if you prefer LaTeX, you were largely on your own. Other Dutch universities, e.g., (Delft)[https://www.overleaf.com/latex/templates/tu-delft-presentation/jcxrmnxssdst], (Leiden)[https://www.overleaf.com/latex/templates/leiden-university-beamer-theme/rsqdqhdcnsgy], already had polished beamer themes.

Utrecht didn't, so I built one! `beamer-uu' is a Beamer theme that follows the [UU brand guidelines](https://www.uu.nl/en/organisation/corporate-identity/brand-policy). It covers the common presentation needs: section dividers, standout slides, a thank-you frame, multi-author conference title pages, and pre-configured code listings.

The theme has been submitted to the Overleaf template gallery, so you'll soon be able to use it directly from Overleaf without any local installation. The source is on GitHub at https://github.com/joszuijderwijk/beamer-uu. If you run into a bug, have a feature request, or want to contribute: pull requests and issues are welcome.
