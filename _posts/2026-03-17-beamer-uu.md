If you've ever prepared a presentation at Utrecht University, you'll know the struggle: PowerPoint templates [exist](https://www.uu.nl/en/organisation/corporate-identity/powerpoint-keynote) and get the job done, but if you prefer LaTeX, options were limited. Other Dutch universities, e.g., [Delft](https://www.overleaf.com/latex/templates/tu-delft-presentation/jcxrmnxssdst) and [Leiden](https://www.overleaf.com/latex/templates/leiden-university-beamer-theme/rsqdqhdcnsgy), already had polished beamer themes on Overleaf.

Utrecht does have [`uucls`](https://github.com/UtrechtUniversity/uucls), an Beamer package that implements the UU Keynote template. I took a different approach with `beamer-uu`, a Beamer theme that follows the [UU brand guidelines](https://www.uu.nl/en/organisation/corporate-identity/brand-policy) and features a brand new title slide, section dividers, standout slides and a thank-you frame.

The theme has been submitted to the [Overleaf template gallery](https://www.overleaf.com/latex/templates/utrecht-university-beamer-template/srfwgqcwqncf), so you can use it directly from Overleaf without any local installation. The source is on [GitHub](https://github.com/joszuijderwijk/beamer-uu). If you run into a bug, have a feature request, or want to contribute: pull requests and issues are welcome.
